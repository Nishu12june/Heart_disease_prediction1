Notes / Input Guide
  • Select Patient: Choose the registered patient.
  • Chest Pain (CP)
    0 = Typical Angina
    1 = Atypical Angina
    2 = Non-anginal Pain
    3 = Asymptomatic
  • Resting Blood Pressure
    Normal: 90–120 mmHg
  • Cholesterol
    Normal: Below 200 mg/dL
  • Fasting Blood Sugar
    Less than 120 = 0
    Greater than 120 = 1
  • Rest ECG
    0 = Normal
    1 = ST-T Abnormality
    2 = Left Ventricular Hypertrophy
  • Maximum Heart Rate
    Usually between 60–202 bpm
  • Exercise Angina
    No = 0
    Yes = 1
  • Old Peak
    ST depression during exercise.
  • Slope
    0 = Upsloping
    1 = Flat
    2 = Downsloping
  • Major Vessels (CA)
    Number of vessels (0–3)
  • Thal
    1 = Normal
    2 = Fixed Defect
    3 = Reversible Defect
